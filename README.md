# Site Dra. Nathalia F. M. Morais

Site estático de uma página (odontologia em Mogi das Cruzes/SP).

- `index.html` — página completa (fotos embutidas em base64).
- Para editar contatos/endereço, altere o bloco `CONFIG` no início do script do `index.html`.

## Publicação

Hospedado na Vercel como site estático (sem build). Cada push na branch `main` publica automaticamente.
